# Notes for coding agents

- Slides are `Slides.md` (Marp). Build with `just build` (output in `_site/`), as CI does.
- **Images:** never link remote images in slides. Save them to `assets/` at ~1920 px long edge. See the "Gotcha" section in `README.md` for why (PDF size).
- **GitHub Actions:** pin actions by commit SHA. Ask the maintainer before adding any action not from the `actions/*` org.
